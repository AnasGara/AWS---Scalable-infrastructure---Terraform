This is a curated reconstruction for presenting the project's engineering sequence. It is not evidence of two months of actual development, continuous work, AWS operation, or professional employment. Each reconstructed commit repeats this disclosure in its message body. Subsequent work should use its actual timestamps.

Some intermediate revisions are scaffolding and are not deployable independently; the final revision is the tested project described in VALIDATION.md.
